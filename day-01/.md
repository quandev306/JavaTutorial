# Bài tập Ngày 1-5: Java Core Basics

## Mục tiêu
Làm quen với cú pháp Java, kiểu dữ liệu nguyên thủy, Wrapper classes và String Pool.

## Bài tập 1: Primitive vs Wrapper
Tạo một chương trình Java (`PrimitiveVsWrapper.java`) thực hiện các yêu cầu sau:
1.  Khai báo các biến kiểu `int`, `double`, `boolean`.
2.  Khai báo các biến kiểu `Integer`, `Double`, `Boolean` tương ứng.
3.  Thử gán giá trị `null` cho biến `int` và biến `Integer`. Quan sát lỗi biên dịch bằng comment.
4.  So sánh hai số `Integer` có giá trị 100 bằng `==`.
5.  So sánh hai số `Integer` có giá trị 1000 bằng `==`.
6.  Sử dụng `.equals()` để so sánh chuẩn xác.
7.  In ra màn hình kết quả và giải thích tại sao (liên quan đến Integer Cache).

## Bài tập 2: String Pool
Viết chương trình `StringPoolDemo.java` kiểm chứng String Pool:
1.  Tạo `String s1 = "Hello";`
2.  Tạo `String s2 = "Hello";`
3.  Tạo `String s3 = new String("Hello");`
4.  So sánh:
    *   `s1 == s2`
    *   `s1 == s3`
    *   `s1.equals(s3)`
5.  In ra kết quả và giải thích sự khác biệt giữa Literal String và Object String.
